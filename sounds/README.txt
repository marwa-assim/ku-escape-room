Put a cheering sound file here named:

    cheer.mp3

The Player Screen will use it for the Support Panel's "Congratulation"
button. Any format the browser can play works (mp3, ogg, wav) - if you
use a different name or format, change CHEER_SOUND_FILE near the top of
the congratulation section in player-screen.js.

If no file is present, the screen falls back to the built-in synthesised
crowd, so nothing breaks.

Use a sound you are allowed to use: something royalty-free / CC0, or one
you recorded yourself. Do not take audio from YouTube videos.
